# 中转站使用方式调整通知

各位同学：

近期，OpenAI 加强了管理策略，中转 Pro 账号在多分发等使用场景下出现了“降智”的情况。为改善使用体验，中转站将调整使用方式，请大家按以下说明修改配置和使用习惯。

> [!IMPORTANT]
>
> 文中的 ***服务器公网 IPv4 地址已进行脱敏处理，***统一以 `222.XX.XX.XX` 表示，完整 IPv4 地址将在 QQ 群内说明。修改配置或访问页面前，请将脱敏占位符替换为实际地址。

## 1. 修改配置文件

进入 `.codex` 文件夹，找到并打开 `config.toml`：

- Windows：在资源管理器地址栏输入 `%USERPROFILE%\.codex`。
- Linux：在终端执行以下命令，再打开该目录中的 `config.toml`。

```bash
cd ~/.codex
```

请修改以下三项：

### 1.1 更新 API_KEY

`API_KEY` 由管理员统一分发，请将当前使用的密钥更新为管理员提供的新密钥。

请勿将真实密钥提交到公开仓库或发布到公开页面。

### 1.2 修改 name

在当前使用的模型提供方配置段（`[model_providers.<当前提供方名称>]`）下，将 `name` 修改为：

```toml
name = "OpenAI"
```

### 1.3 修改 base_url

在同一配置段下，将 `base_url` 修改为：

```toml
base_url = "http://222.XX.XX.XX:18316/v1"
```

## 3. 配置生图功能

上述 `base_url` 和 `API_KEY` 也可用于生图，配置相应 Skill 即可。

完成 Codex 环境配置后，可以让 AI 协助下载并配置以下 Skill：

[m0rtzz-imagegen](https://github.com/M0rtzz/m0rtzz-imagegen)

其余事项与原中转站保持一致，包括计费规则和基础使用方式等。
