# 中转站使用方式调整通知

此前 Tibo 点名过 [`sub2api`](https://x.com/thsottiaux/status/2090675027670978569)，但更推荐使用 [`CLIProxyAPI（CPA）`](https://x.com/thsottiaux/status/2076119366647894371)。为尽量避免模型降智，我们决定今后采用 CPA。麻烦大家按以下说明修改配置。

> [!IMPORTANT]
>
> 文中的 ***服务器公网 IPv4 地址已进行脱敏处理，***统一以 `222.XX.XX.XX` 表示，完整 IPv4 地址将在 QQ 群内说明。修改配置或访问页面前，请将脱敏占位符替换为实际地址。

## 1. 修改配置文件

进入 `.codex` 文件夹，找到并打开 `config.toml` 和 `auth.json`：

- Windows：在资源管理器地址栏输入 `%USERPROFILE%\.codex`。
- Linux：在终端执行以下命令，再打开该目录中的 `config.toml` 和 `auth.json`。

```bash
cd ~/.codex
```

请修改以下两项：

### 1.1 更新 API_KEY

`API_KEY` 由管理员统一分发。打开 `auth.json`，将 `OPENAI_API_KEY` 的值替换为管理员提供的新密钥，保留其他字段不变。

以下为仅包含密钥字段的格式示例，请将占位文字替换为实际密钥：

```json
{
  "OPENAI_API_KEY": "替换为管理员提供的新密钥"
}
```

请勿将真实密钥提交到公开仓库或发布到公开页面。

### 1.2 修改 base_url

打开 `config.toml`，在当前使用的模型提供方配置段（`[model_providers.<当前提供方名称>]`）下，将 `base_url` 修改为：

```toml
base_url = "http://222.XX.XX.XX:18316/v1"
```

## 2. 查询用量与额度

将以下地址中的脱敏占位符替换为实际地址后，在浏览器中打开页面，输入自己的 `API_KEY`，即可查询使用情况：

[http://222.XX.XX.XX:18316/v0/resource/plugins/cpa-key-billing/usage.html](http://222.XX.XX.XX:18316/v0/resource/plugins/cpa-key-billing/usage.html)

## 3. 配置生图功能

上述 `base_url` 和 `API_KEY` 也可用于生图，配置相应 Skill 即可。

完成 Codex 环境配置后，可以让 AI 协助下载并配置以下 Skill：

[m0rtzz-imagegen](https://github.com/M0rtzz/m0rtzz-imagegen)

倍率、计费规则及其他使用设置与原中转站保持一致。

如有不便或建议，欢迎反馈，我们会持续改进。
